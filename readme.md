# TEXTY - Cyber Puzzle Quest

A futuristic 3D text puzzle game playable directly in your browser via GitHub Pages.

## 🎮 Features

- **12 Unique Levels** with diverse puzzle types:
  - Binary decryption
  - Caesar cipher
  - Number sequences
  - Anagrams
  - Hexadecimal conversion
  - Logic puzzles
  - Math challenges
  - Pattern recognition
  - Riddles
  - Code breaking
  - Fibonacci sequences

- **Gamification Elements**:
  - Score system with time bonuses
  - Achievement system (6 achievements to unlock)
  - Power-ups (Hints, Time Extension, Skip)
  - Level progression with star ratings
  - Leaderboard potential

- **Futuristic 3D Design**:
  - Neon cyberpunk aesthetic
  - Animated holographic puzzle frames
  - Glitch text effects
  - 3D rotating elements
  - Particle grid background
  - Smooth transitions and animations

## 🚀 Play on GitHub Pages

1. Go to your repository settings
2. Navigate to "Pages" section
3. Select your branch and save
4. Visit `https://yourusername.github.io/your-repo-name`

## 🎯 How to Play

1. Click "ENTER THE GRID" to start
2. Read the puzzle carefully
3. Type your answer in the input field
4. Press "DECRYPT" or hit Enter
5. Complete levels before time runs out
6. Earn points based on speed and difficulty
7. Unlock achievements as you progress

## 💡 Power-Ups

- **💡 Hint** (3 available): Reveals a helpful clue
- **⏰ Time** (2 available): Adds 30 seconds to the timer
- **⚡ Skip** (1 available): Skip to next level with partial points

## 🏆 Achievements

- First Decrypt - Complete your first puzzle
- Speed Demon - Solve a puzzle in under 10 seconds
- Perfectionist - Complete 5 levels without hints
- Cyber Scholar - Reach level 5
- Grid Master - Complete all 12 levels
- Power User - Use all three types of power-ups

## 🛠️ Technologies Used

- HTML5
- CSS3 (with advanced animations and 3D transforms)
- Vanilla JavaScript (no frameworks required)

## 📱 Responsive Design

The game adapts to different screen sizes and works on desktop and mobile devices.
